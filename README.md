# GCollector Releases

Release builds of **GCollector**, the offline Android inventory collector app by [Gestoque](https://gestoque.com.br). The app source code is private; this repository only hosts the published builds.

## What is GCollector

Android app (Kotlin) used by inventory teams and retailers to count stock on the shelf, even without a connection. Counts are synced and integrated with the retailer's ERP through the Gestoque platform.

## Download

Get the latest APK from the [Releases](../../releases) page. On Android, allow installation from this source when prompted.
